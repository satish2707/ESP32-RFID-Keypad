# ESP32 RFID Keypad

ESP32-based RFID user access and recharge system using an MFRC522 RFID reader, 0.96 inch SSD1306 OLED display, four-button keypad, EEPROM storage, buzzer, and status output.

## Project

Open the Arduino sketch:

`ESP32_RFID_Keypad/ESP32_RFID_Keypad.ino`

## Features

- Admin card based setup mode
- Add user RFID card
- Delete user RFID card
- Recharge user balance
- Check user balance
- Deduct balance when a valid user card is scanned
- OLED animations and status messages
- EEPROM storage for up to 10 users
- Four-button menu navigation
